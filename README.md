# Ekashmi Rathore — Professional Portfolio

Personal website for **Ekashmi Rathore, PhD** — Scientist & Innovation Strategist.
Hosted with GitHub Pages as a project site under Mahesh's account:

**Live URL (once published): https://mahashg.github.io/ekashmi/**

## Files
- `index.html` — all content (single page, chapters like drlebedev.com)
- `style.css` — styling, responsive for mobile
- `script.js` — footer year
- `assets/ekashmi.png` — headshot provided Oct 2026
- `assets/Ekashmi-Rathore-Profile.pdf` — full profile PDF (Download button)

## Publish steps
1. Create a public repo named `ekashmi` under github.com/mahashg
2. Push these files to `main`
3. Repo Settings → Pages → Source: Deploy from branch `main` / root
4. Wait 1–2 minutes, open https://mahashg.github.io/ekashmi/

## Editing
